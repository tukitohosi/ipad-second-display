# iPad互联使用说明

0.3.0-preview 已完成本地 Release 构建、自动化测试及隔离界面预览，并按版本名封装。真实 iPad、60 分钟连续运行和干净机器安装仍待验收。配置格式升级为 v3；旧安装包不包含本轮修改。

## 工作方式

鼠标始终连接 Windows。程序创建一块 Windows 扩展显示器并把它发送到
iPad；当指针越过电脑屏幕右边缘时，Windows 会自然把指针移入该扩展
显示器，因此不需要切换鼠标的蓝牙通道。

这里控制的是显示在 iPad 上的 Windows 应用，不是 iPadOS 主屏、设置或
Safari 等原生应用。

副屏使用 Windows 自己的桌面、资源管理器、任务栏和应用窗口。程序不再默认显示覆盖桌面的快捷方式启动器，也不再代替 Windows 分配任务栏窗口。扩展桌面不会自动复制主屏的所有图标；可按 Windows 的正常方式移动图标、窗口并设置副屏缩放。

## 首次准备

1. iPadOS 16 或更高版本安装官方 OpenDisplay 接收端。推荐加入公开
   TestFlight：<https://testflight.apple.com/join/3NYaY11c>；若测试名额或
   测试版本不可用，再按上游说明用 Xcode 自行签名：
   <https://github.com/peetzweg/opendisplay#iphone-app>
2. Windows 和 iPad 连接同一个由你控制的 5 GHz 私有局域网或私人热点。
3. Windows 的该网络配置必须标记为“专用网络”。程序默认拒绝在“公用
   网络”上传输屏幕；不要为了酒店、校园或访客 Wi-Fi 关闭这项保护。
4. Parsec Virtual Display Driver 是独立的第三方前置组件。安装包不包含、
   不安装也不卸载它。驱动共存测试必须先运行 `tools\safety` 中的基线
   脚本，确保现有 GameViewer 驱动保持不变。

## 使用

1. 先在 iPad 前台打开 OpenDisplay。
2. 启动 `iPad互联.exe`，主面板会自动打开，关闭窗口后程序继续驻留托盘。
3. 从“局域网发现”选择 iPad 并添加，或者插入 USB 数据线。发现失败时可在
   “高级设置”中手动填写 `192.168.1.42 iPad Pro`。
4. 默认参数为均衡预设（60 fps、30 Mbps）、自动连接开启、可信网络保护开启。
5. 点击主面板“自动连接”，或先选定设备再点“连接所选”。程序优先尝试上次成功通道；Wi-Fi 会按顺序尝试该设备
   的已知地址，本轮地址耗尽或整体超时后再尝试下一设备及可用备用通道。连接后，Windows“显示设置”中应出现独立扩展屏；
   默认位于主屏右侧。

主面板会区分等待 OpenDisplay、准备显示器、重连、非专用网络、驱动不可用和
分辨率冲突，并给出对应处理方式。“导出诊断”生成已遮蔽 IPv4、MAC、设备/网络 UUID、USB 标识和用户
目录的本地报告；不会上传任何内容。

主动断开或退出时，程序只移除自己本次会话创建的 Parsec 虚拟屏，不会
禁用、卸载或清理 GameViewer 驱动。

## 自动识别与 MAC 辅助连接

首次通过“局域网发现”添加或手动连接后，程序会记录 OpenDisplay 的稳定设备 ID。后续连接优先使用该 ID 对应的 Bonjour 地址；地址变化时，不需要把 IP 当成永久设备身份。

当连接成功、接收端 ID 正确且 Windows 当前可取得对应 MAC 时，程序才记录“设备 ID + 本次网络与网卡 + MAC”的关联。以后按“在线 Bonjour 地址 → 本网络已验证 MAC 对应 IP → Bonjour 主机名 → 最近保存的 IP”依次尝试，仍通过 IP 和端口连接，并再次核对接收端 ID。没有稳定 ID 或出现关联冲突时，MAC 不参与自动匹配。

MAC 功能读取 Windows 可见的邻居缓存，必要时只刷新已发现或已选择 IP 的记录，不扫描全部网段。列表为空不等于 iPad 不存在；跨路由、设备隔离、休眠或缓存过期时可能无法取得 MAC，Bonjour、手动地址及 USB 仍然可用。发现普通网络设备的 MAC 也不代表它支持副屏。

iPad 私有 Wi-Fi 地址按网络不同，并可能轮换。保持此隐私功能开启即可；接收端 ID 正确的成功连接会更新当前网络的关联。USB 使用自己的设备标识，不使用 Wi-Fi MAC。MAC 和稳定 ID 都不是加密认证机制。参见 [Apple 私有 Wi-Fi 地址说明](https://support.apple.com/en-us/102509)。

配置保存在 `%APPDATA%\MouseLink\config.json`。旧配置升级为 v3 时保留设备、名称、地址、画质及其他连接偏好，同时关闭旧启动器和任务栏路由。历史 `macHint` 仅保留为诊断字段，不会被当成已经验证的 MAC 关联。保存仍采用临时文件、原子替换和 `.bak` 恢复。

## 先预览界面

在源码目录运行；脚本会优先使用构建产物，清理构建缓存后使用本版便携程序：

```powershell
.\scripts\preview-ui.ps1
```

该模式只显示界面，不自动连接设备或创建副屏，不读取、覆盖真实配置；预览日志写入临时目录。先检查小窗口、最大化、高 DPI、长设备名以及“连接设置”和发现列表能否完整滚动访问。界面通过后，再按《实机验收》检查副屏清晰度、缩放、颜色、输入及重连。

## 无驱动自检

下面的命令只读取现有显示器，不创建、删除或改分辨率：

```powershell
.\iPad互联.exe --list-displays
.\iPad互联.exe --capture-existing "\\.\DISPLAY1" 127.0.0.1
```

第二条命令需同时运行仓库里的 `tools\mock_receiver.py`，用于验证 DXGI
捕获、H.264 编码和 OpenDisplay 协议。它不是正式副屏模式。

产品构建已禁用上游按全局数字索引删除显示器的 `--remove-display` 命令。
异常恢复只能使用安装时生成的实例 ID 与 INF 收据进行精确回滚。

## 当前限制

- OpenDisplay v3 使用未加密、未认证的 TCP 协议，只允许可信私有局域网。
- iPad 接收端必须保持前台。
- 首版不包含音频、剪贴板、多台不同分辨率 iPad 或 iPad 原生应用控制。
- 不要同时启动多个 iPad互联进程。可配置多个备用设备，但本版同一时间仅连接并传流一台 iPad。
- 默认目标为稳定 60 fps；120 Hz 不是 0.2.0 的验收门槛。
- 画面通过 H.264 传输；接近原生的桌面交互不等于无压缩、无延迟或 HDR 完整支持。真实 iPad 的字体、色彩和性能仍需实测，本地构建或界面预览不能替代。
- 自用测试版 EXE 未购买商业代码签名证书，运行前请核对发布目录中的
  `SHA256SUMS-0.3.0-preview.txt`。

## 卸载

卸载器只删除 iPad互联程序和快捷方式，不删除任何显示驱动、设备节点、
防火墙规则或用户已有配置。第三方驱动需要由其官方卸载器单独处理。
